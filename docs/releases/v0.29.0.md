# v0.29.0 (apworld 0.29.0, mod 0.60.0): public playtest, second build

This is the second public playtest build of the Final Fantasy Resonance randomizer for [Archipelago](https://archipelago.gg/). It fixes what the v0.28.0 players reported: items that came again after a mod update or on a second PC, late bosses with far too much HP, an island you could land on without its Unlock, and a few logic gaps. Every location also has a new, readable name. Please report how your seed went with the feedback template in the [Playtester guide](https://github.com/wrjones104/ffresonance-archipelago/blob/main/docs/playtester_guide.md).

## Downloads

| File | Description |
|---|---|
| `FFRArchipelago.zip` | UE4SS Lua game mod (v0.60.0, build `08cabc86`) |
| `ff_resonance.apworld` | Archipelago world and Final Fantasy Resonance Client (v0.29.0, build `c64e56f7`) |
| `Final Fantasy Resonance.yaml` | Template player YAML with default options |

Make sure the mod and the apworld come from the same release. The mod writes its version and build to `UE4SS.log` on load (`version 0.60.0 (build 08cabc86)`), and the client prints its own when it starts. The client warns you if a seed was generated with a different apworld build.

## Changes since v0.28.0

### Fixes

- **Items no longer come again after a mod update or on a second PC.** The save now keeps its seed and how many items it has received. A save loaded on another PC, or after `ap_state.txt` is deleted, links itself to the seed and gets only the items it lacks. You no longer need `/bind` for that. Saves from v0.28.0 get the stamp the first time they load with this mod.
- **The island between Grandshelt and Lanzelt** belongs to Grandshelt now. You can no longer land there without Grandshelt Unlock.
- **New Game (Archipelago) waits for the client.** If the client is not connected when you start a new game, the mod shows a message and holds the prologue skip until the client connects. Before, the new game went on to the normal story.
- **The client rewrites `ap_in.txt`** if it is deleted while the client is connected.

### Scaling

- **Late bosses have much less HP.** Boss HP now follows a curve fitted to the game's own bosses. Siren at level 57 has about 320,000 HP (it had 2,434,404).
- **Physical damage keeps up with magic.** Enemy Defence grows more slowly with level than the other stats.
- **Small parties have a chance.** Bosses lose 12% of their power for each empty slot in a party of four.

### Logic

- **World Map Shiny 167** (Gronoa's north-west coast) needs the Airship.
- **Nameless Ruins:** Chests 2, 4 and 5, its Tablet Shard and the Tellus fight need both Liquid Flame and Iron Giant.

### Location names

Every chest, shiny, Tablet Shard and radar treasure has a new name that says where it is. The names give the continent, the place and a spot in it, such as `Grandshelt - Earth Shrine - Interior Central-East Alcove Chest` or `Gronoa - World Map - Shiny on Far-NW Coastal Terrace`. The location ids did not change, so a seed generated with v0.28.0 still works with the new client. The old names are in `data/location_names.tsv` in the repository.

### Upgrading from v0.28.0

Replace the `FFRArchipelago` folder and the apworld, then generate a new seed to get the logic fixes and the new names. **Keep `ap_state.txt`** if you are in the middle of a seed: the first time the save loads with the new mod, the mod stamps the save with it. After that the stamp travels with the save, including through Steam Cloud.

## Known issues

- **ModSettings crash.** The `ModSettings` UE4SS Lua mod (`Mods\ModSettings`, from FFR Modding Tools) can crash the game a second or two after a map change, with or without this mod. To avoid it, turn off **Hint on map load** in the ModSettings panel (F10), or set `ModSettings : 0` in `Mods\mods.txt`. The second option turns off only its Lua key binding; the ModSettings Blueprint mod still works.
- **Mt. Thunderclap's shortcut ladder has no mesh.** Examine at the top of the cliff lets the ladder down as in the base game, and you can climb it, but it is invisible. In the story, paying Lid makes it show.

## Requirements and installation

You need *Final Fantasy Resonance* on Steam (Windows), a UE4SS build for Unreal Engine 5.6 (`v3.0.1 Beta` or newer), and Archipelago 0.6.7 or newer. See the [README](https://github.com/wrjones104/ffresonance-archipelago#installation) for full details, or follow the quick steps below:

1. Install UE4SS into `FINAL FANTASY RESONANCE\FFRS\Binaries\Win64\`.
2. Extract `FFRArchipelago.zip` into `...\Win64\ue4ss\Mods\` so you end up with `Mods\FFRArchipelago\Scripts`.
3. Double-click `ff_resonance.apworld` or copy it into Archipelago's `custom_worlds` folder.
4. Generate a seed, open the **Final Fantasy Resonance Client** from the Archipelago Launcher, connect, and choose **New Game (Archipelago)** in game.

Disable `FFRRandomizer` if you have it installed, since it edits the same tables. If you use `FFRS_QoL`, leave its encounter rate at `1` and turn off its EXP, gil, MRP, and encounter overrides. Other mods are untested.

## Not done yet

- Quests, NPCs, and some pickup spots that give key items or visions in the base game are not locations yet. They still grant their normal rewards, so you can end up with a key item or vision twice.
- The Research Center Ruins' key cards and the Zoldaad Throne Key are not locations yet.
- Espers are still obtained the vanilla way, except Siren, which you start with.
- The Chamber of Arms and the Arena are untouched.
- Boss logic is still new. If logic sends you to a boss you cannot beat, or locks out one you beat easily, report it with your party members, levels, visions, Magicite, and gear.
